Goal
- Add user avatar upload and persist relative URL to DB (field: users.image_url)

High-level changes

1) API: user avatar upload
- File: api/api_v1/users.py
- Added endpoint: POST /api/v1/users/me/avatar
  - Auth: requires an active user (Depends(current_active_user))
  - Input: multipart/form-data field 'file' (UploadFile)
  - Behavior:
    - Saves file to disk via profile/main.py::save_user_avatar(user_id, file)
    - Stores returned relative URL (e.g. /media/user_img/<user_id>.<ext>) into User.image_url
    - Persists to DB via users_db.session.commit() + refresh()
    - Clears cache namespace: settings.cache.namespace.users_list
  - Output: UserRead (includes image_url)

2) File storage helper (no duplication)
- File: profile/main.py
- Reused existing save_user_avatar(user_id, file) -> str
  - Saves to: <BASE_DIR>/media/user_img/

How to verify (manual checklist)

1) App start
- python main.py

2) Register + login (registration does not imply authentication)
- POST /api/v1/auth/register
- POST /api/v1/auth/login
  - In Swagger OAuth2 form: grant_type=password, username=<email>, password=<password>
  - Expect Set-Cookie for auth_user (cookie transport)

3) Check auth works
- GET /api/v1/users/me

4) Upload avatar
- POST /api/v1/users/me/avatar
  - multipart/form-data: file=@avatar.jpg
  - Expect response UserRead with non-null image_url

5) Check static access
- Open returned URL:
  - http://127.0.0.1:8000<image_url>
  - Example: http://127.0.0.1:8000/media/user_img/<uuid>.jpg

Security / risk review (current behavior)

- Upload endpoint is protected by auth (current_active_user)
- CORS now allows credentials; origins list remains explicit (not '*')
- File upload currently does not validate:
  - content-type
  - allowed extensions
  - file size limits
  - image decoding
  Recommended hardening (optional): validate MIME/extension, enforce max size, generate safe extension, and/or re-encode image.

Git hygiene note
- Do not commit uploaded runtime files (media/user_img/*).
- Recommended: add media/user_img/ to .gitignore and remove already staged file from git index.
